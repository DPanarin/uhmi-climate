Під час роботи з API я зібрав вісім пропозицій; кожна — невелика зміна на сервері. Найпростіші й найкорисніші — стиснення і кешування: ряд проєкцій стискається з 47 до 8 кілобайтів. Помилка 500 на невідому територію виглядає як збій сервера; краще 404. Ключ API видно в браузері, тому варто обмежити його строк дії і домени. І найважливіше — виділене жовтим: зараз значення для карти є лише всередині коду сайту, тому я витягую їх скриптом. Endpoint із цими значеннями дозволить оновлювати дані без перебудови сайту. Деталі — в docs/presentation/api-improvements.md.
