# Матеріали презентації

Презентація прототипу для Українського гідрометеорологічного інституту (жовтень 2026).

| Файл | Що всередині |
| --- | --- |
| Слайди (10) | Онлайн-презентація з нотатками доповідача; завантаження в PPTX або PDF — з її меню. Посилання — у власника репозиторію. |
| [`deck/`](deck/) | Вихідні файли слайдів (HTML). Зображення в них — це посилання на файли, завантажені в онлайн-презентацію. |
| [`results.md`](results.md) | Було / стало: вимірювання Lighthouse, пам'ять, швидкість карти. |
| [`demo-script.md`](demo-script.md) | Сценарій демонстрації на 3–5 хвилин, з текстом для доповідача. |
| [`api-improvements.md`](api-improvements.md) | Що покращити в API. |
| [`handover.md`](handover.md) | Передача проєкту: запуск, конвеєр даних, рішення, обмеження. |
| [`screenshots/`](screenshots/) | Пари «було» / «стало» (`old-*` / `new-*`) для 390, 1366 і 1440 px. Окремо — вигляд за посиланням з графіком і телефон. |
| [`lighthouse/`](lighthouse/) | Звіти Lighthouse (медіанні запуски). Ключ базової мапи в адресах плиток замінено на `REDACTED`. |
